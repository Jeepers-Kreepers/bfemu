# Парный опыт «Возмущение — порыв ветра»: ROLL, D Max 40 → 50

Вариант заданного воздействия: постоянный внешний момент −0,08 Н·м по оси ROLL тела
FRD в течение 120 мс; все стики по центру, газ 1300. Это не аэродинамический расчёт
и не скорость ветра. Build 03 — теоретический профиль, до ARM — жёсткий стенд,
после ARM — свободное тело без земли, без воздушного сопротивления и батареи.
Использована исследовательская версия Betaflight 4.5.4 с инструментированным PID,
изменёнными часами и планировщиком. Остальные настройки и фильтры — заводские.

Два повтора каждой настройки завершились, проверки начального состояния, команды,
воздействия, фазы 32 PID-циклов на 4-мс кадр и допусков разброса пройдены.
Разброс записанных значений внутри каждой пары повторов равен нулю. В этом опыте
пиковая абсолютная ошибка равна 11,1693 °/с для обоих вариантов; восстановление
в диапазоне ±5 °/с до конца окна — 0,061625 с после окончания воздействия.
Насыщение моторов на концах кадров не обнаружено. Это не универсальный вывод
об эффекте D Max и не гарантия повторяемости на другой системе.

профиль и хеши. Отчёт можно пересчитать командой:

python3 tools/sitl_lockstep_report.py docs/research/sitl-lockstep-gust-roll-v1 --html ./gust-report.html
