# Ступень с землёй и воздухом — PITCH P49 → P55

Два независимых повтора каждого варианта, P/I/D Max 49/84/46 и 55/84/46,
стик 1650, газ 1400, профиль Build 03. До ARM плоская земля, далее взлёт;
окно сравнения проверено на отсутствие контакта с землёй. После дизарма
запись продолжена 500 кадров (2 с). `ground-air-v1` — упрощение, не полная
модель ArduPilot; источник и параметры перечислены в `summary.jsonl` и
[документации](../../flight-model.md#земля-и-сопротивление-воздуха-проверка-нового-режима).

Оба варианта прошли проверки начального состояния и повторяемости всех записанных
величин. Перерегулирование 24,5109 → 25,2435%, время установления 0,092375 →
0,120750 с. Насыщений на конечных снимках не обнаружено. Для первого варианта
к концу двух секунд после дизарма аппарат был на земле, тело остановлено моделью
контакта. Это результаты теоретической модели, не измерения настоящего коптера.

Исходные трассы сжаты; хеши и события в журнале. Для пересчёта отчёта:

```bash
python3 tools/sitl_lockstep_report.py docs/research/sitl-ground-air-step-v1 --html ./ground-step.html
```
