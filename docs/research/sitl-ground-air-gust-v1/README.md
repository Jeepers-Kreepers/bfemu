# Порыв с землёй и воздухом — PITCH P49 → P55

Два независимых повтора каждого варианта, P/I/D Max 49/84/46 и 55/84/46,
стики по центру, газ 1400, профиль Build 03. Возмущение — постоянный момент
+0,05 Н·м вокруг PITCH тела в течение 0,2 с, а не рассчитанная сила ветра.
До ARM плоская земля, далее взлёт; окно сравнения проверено на отсутствие контакта
с землёй. После дизарма запись продолжена 500 кадров (2 с). `ground-air-v1` —
упрощение, не полная модель ArduPilot; параметры в журнале и
[документации](../../flight-model.md#земля-и-сопротивление-воздуха-проверка-нового-режима).

Оба варианта прошли проверки начального состояния и повторяемости всех записанных
величин. Пиковая абсолютная ошибка 5,5542 → 5,3099 °/с, время восстановления
после окончания воздействия 0,033000 → 0,028625 с. Насыщений на конечных
снимках не обнаружено. Через две секунды после дизарма первый вариант оставался
в воздухе; вращение по PITCH уменьшилось с 0,0904 до 0,0806 °/с по модулю.
Это результаты теоретической модели, не измерения настоящего коптера.

Исходные трассы сжаты; хеши и события в журнале. Для пересчёта отчёта:

```bash
python3 tools/sitl_lockstep_report.py docs/research/sitl-ground-air-gust-v1 --html ./ground-gust.html
```
