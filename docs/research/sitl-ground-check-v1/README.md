# Проверки аппарата на земле при дизарме

Два независимых запуска lockstep-SITL по 1500 кадров (6 с моделируемого времени),
с неподвижной моделью земли и воздуха `ground-air-v1`, профиль Build 03. На каждом
кадре контакт с землёй подтверждён; физическое положение, угловая скорость,
команды моторов и отсчёты гироскопа FC по всем осям нулевые; удельная сила
на IMU (0, 0, −9,80665) м/с². Исходный JSONL и хеши — в архиве. Этот опыт
использовал снимок драйвера до добавления 2-секундного продолжения после дизарма;
стационарный сценарий не был изменён.

Дополнительно отдельная сборка и сценарий из `check_ground_attitude.py` дали
18 ответов MSP_ATTITUDE с неизменными значениями (0, 0, 0) при 1500 кадрах на
земле. Ошибок опроса не было. Опрос MSP не проверяет визуальную отрисовку
Configurator и не доказывает причину ранее замеченного вращения.
