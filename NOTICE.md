# Лицензии и сторонние материалы

## Код эмулятора

`bfemu/`, `tools/`, `tests/` и командные файлы написаны авторами проекта и распространяются
по лицензии **GNU GPL версии 3 или новее** (полный текст — в файле `LICENSE`).

GPLv3 выбрана осознанно: эмулятор воспроизводит поведение прошивки Betaflight, сверяется с её
исходниками и живёт в той же экосистеме, где и Betaflight (GPLv3), и Betaflight Configurator (GPLv3).
Совместимая лицензия снимает вопросы о производности и позволяет переносить фрагменты логики в обе стороны.

> Если автор предпочитает другую лицензию (MIT/Apache-2.0), её можно поставить **только** после того,
> как из репозитория уберут скопированные исходники Betaflight (см. ниже): сами по себе наши файлы
> производными не являются, но соседство GPL-файлов в одном дереве требует аккуратности.

## Скопированные исходники (эталоны для сверки)

| Каталог | Источник | Версия | Лицензия |
|---|---|---|---|
| `docs/betaflight-4.5.4/` | https://github.com/betaflight/betaflight | тег `4.5.4` | GPL-3.0-or-later |
| `docs/bf454-failsafe/` | https://github.com/betaflight/betaflight | тег `4.5.4` | GPL-3.0-or-later |
| `docs/configurator-2026.6.2/` | https://github.com/betaflight/betaflight-configurator | тег `2026.6.2` | GPL-3.0-or-later |

Это **неизменённые** файлы прошивки и конфигуратора. Они лежат в репозитории как эталон: по ним
сверяются форматы MSP, порядок полей, биты фич и поведение вкладок. Авторские права на них
принадлежат участникам проектов Cleanflight/Betaflight; лицензионные заголовки сохранены внутри файлов.

Вместо копий их можно подтягивать скриптом — это уменьшит репозиторий на 1,4 МБ:

```bash
git clone --depth 1 --branch 4.5.4 https://github.com/betaflight/betaflight /tmp/bf454
git clone --depth 1 --branch 2026.6.2 https://github.com/betaflight/betaflight-configurator /tmp/bfc
python3 tools/gen_data.py /tmp/bf454       # пересобирает bfemu/data/bf_data.json
```

## Торговые марки

«Betaflight» — название стороннего проекта; bfemu не является его частью, не связан с его
разработчиками и лишь воспроизводит протокол обмена для отладки наземного ПО.
